# Task: XDG-Compliant Platform Paths

## Purpose

Replace hardcoded `~/.search-hub/` paths with platform-specific directories using `env-paths` package:

- **Linux**: XDG Base Directory spec (`~/.config/`, `~/.local/share/`)
- **macOS**: Standard macOS directories (`~/Library/`)
- **Windows**: AppData directories (`%APPDATA%`)

This is a **breaking change** but acceptable pre-release with no existing users.
